# Forge contribution testbed

PEGASUS_PUBLIC_CONTRIBUTION_TESTBED_V1

This repository explicitly permits the dedicated Forge Engineering contributor
account to create labeled, unpaid integration-test pull requests containing only
small text fixtures under `commissioning/`.

The tests verify public fork creation, exact patch publication, provider readback,
and idempotent replay. They are not paid bounties, offers of compensation, business
deliveries, or payment evidence. No private project code, credentials, customer
data, or banking details belong here. No GitHub Actions workflow is used.
